# Stand-Up – AI Posture Detection & Wellness App

AI-driven web application that detects whether a user is sitting or standing using computer vision, and reminds them to stand up at healthy intervals.

# Overview

Stand-Up is a full-stack AI wellness platform that promotes healthy posture habits by leveraging real-time webcam input and machine learning-based pose detection. The app continuously monitors the user’s position and notifies them to stand after long periods of sitting — helping to reduce sedentary behavior and improve overall health.

# Features

🧍‍♀️ Real-Time Posture Detection – Uses Google Teachable Machine (Tensorflow-based) to classify user posture via webcam feed.

# Custom Reminders – Allows users to set personalized reminder intervals to stand up or stretch.

📊 Activity Dashboard – Tracks posture trends and session history for health insights.

🔔 Smart Notifications – Integrated browser alerts and background monitoring for minimal interruptions.
